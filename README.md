# 🍽️ Дневник питания с распознаванием еды (Food Diary)

Веб-сервис, который позволяет:

-  загрузить фото блюда;
-  автоматически распознать категорию еды (12 классов);
-  получить примерную калорийность и БЖУ на 100 г;
-  вести ежедневный дневник питания с прогресс-барами и графиками.

Проект выполнен в рамках семестровой работы и демонстрирует полный цикл разработки ML-сервиса с веб-интерфейсом.

---

## Возможности

### Распознавание еды

После загрузки изображения пользователь получает:

- предсказанную категорию блюда;
- уровень уверенности модели;
- примерную калорийность;
- белки, жиры и углеводы на 100 г продукта.

### Дневник питания

- добавление распознанных блюд в дневник;
- учет веса порции;
- автоматический расчет калорий и БЖУ;
- отображение прогресса относительно дневных целей;
- хранение истории питания;
- отслеживание изменения веса пользователя.

Отвечает за:

- рендеринг HTML-страниц;
- аутентификацию пользователей;
- валидацию пользовательского ввода;
- взаимодействие с ML API.

### FastAPI

Отвечает за:

- загрузку обученной модели;
- выполнение предсказаний;
- предоставление REST API.

### SQLite

Хранит:

- пользователей;
- историю распознаваний;
- записи дневника питания;
- данные о весе пользователя.

# 🚀 Запуск проекта

## 1. Запуск через Docker (рекомендуется)

Убедитесь, что установлен Docker Desktop и доступно не менее 4 ГБ оперативной памяти для контейнера с моделью.

```bash
git clone https://github.com/LinaTopakova/Python_sem2.git
cd food-diary
docker-compose up --build
```

После запуска будут доступны:

- Flask: http://localhost:5000
- FastAPI Swagger: http://localhost:8000/docs

---

## 2. Локальный запуск (для отладки)

### Требования

- Python 3.10+
- uv

### Создание окружения

```bash
git clone https://github.com/LinaTopakova/Python_sem2.git
cd food-diary

uv venv
.venv\Scripts\activate   # Windows

uv sync
```

### Запуск FastAPI

```bash
uvicorn api.main:app --host 0.0.0.0 --port 8000 --reload
```

### Запуск Flask

В отдельном терминале:

```bash
$env:ML_API_URL = "http://localhost:8000"
python wsgi.py
```

После запуска откройте:

```text
http://localhost:5000
```

# Интерфейс приложения

## Главная страница (`/`)

Содержит:

- приветствие пользователя;
- карточки перехода к разделам:
  - «Распознать»;
  - «Дневник».

---

## Регистрация (`/register`)

Форма включает поля:

- логин;
- пароль;
- пол;
- рост;
- вес.

Особенности:

- все поля обязательны;
- логин проверяется на уникальность;
- рост и вес валидируются по допустимым диапазонам;
- отображаются flash-сообщения при ошибках ввода.

---

## Вход (`/login`)

Аутентификация по логину и паролю.

Безопасность:

- пароль хранится в виде хэша (`werkzeug.security`).

### Выход (`/logout`)

Завершает пользовательскую сессию.

---

## Профиль (`/profile`)

Позволяет изменять:

- пол;
- рост;
- вес;
- дневную цель по калориям;
- дневную цель по белкам;
- дневную цель по жирам;
- дневную цель по углеводам.

Указанные значения используются для отображения прогресса в дневнике питания.

---

## Распознавание (`/predict`)

Пользователь загружает фотографию блюда.

Процесс:

1. Flask отправляет изображение в FastAPI.
2. FastAPI выполняет предсказание.
3. Результат возвращается в интерфейс.

Отображаются:

- изображение блюда;
- категория;
- уверенность модели;
- калорийность;
- БЖУ на 100 г.

Также доступно добавление блюда в дневник с указанием веса порции.

---

## Дневник питания (`/diary`)

Для выбранного дня отображаются:

- фотография блюда;
- название;
- вес порции;
- калорийность;
- белки;
- жиры;
- углеводы;
- время добавления;
- кнопка удаления записи.

Дополнительно:

### Учет веса

Отдельный блок позволяет сохранить текущий вес пользователя.

### Прогресс целей

Отображаются прогресс-бары по:

- калориям;
- белкам;
- жирам;
- углеводам.

### Аналитика

Графики за последние 7 дней:

- потребленные калории;
- изменение веса.


---

## История (`/history`)

Таблица всех распознаваний, содержащая:

- название блюда;
- калорийность;
- БЖУ;
- дату и время предсказания.

# Безопасность

В проекте реализованы:

- хеширование паролей через `werkzeug.security`;
- защита от CSRF-атак с использованием Flask-WTF;
- серверная валидация пользовательского ввода;
- проверка уникальности учетных записей.

# ML-модель

Используется модель:

**Kaludi/food-category-classification-v2.0**

Особенности:

- архитектура **Swin Transformer**;
- обучена на 101 категориях еды;
- распространяется через Hugging Face Transformers;
- используется для классификации изображений блюд.
